Project 01 · 商品视觉识别

一眼识万物。
从像素到语义。

融合向量检索、文档 OCR 与目标检测，构建端到端商品识别系统。覆盖 23,610 类 SKU，单张推理 380ms。

系统概览

三大引擎，一套系统。

将 DINOv3 向量嵌入检索、DeepSeek-OCR / HunyuanOCR 文档理解、YOLO 目标检测三大能力整合为统一的商品识别管线，支持从图片输入到结构化输出的全流程。

核心引擎

每个模块，都是利器。

🧬

DINOv3 向量检索

基于 DINOv3 ViT-Large 生成 1024 维 L2 归一化嵌入，采用 Multi-Similarity Loss 训练。覆盖 23,610 个商品类别，支持 TensorRT FP16 加速推理。

📄

DeepSeek-OCR / HunyuanOCR

DeepSeek-OCR 从 LLM 视角研究视觉编码器，支持原生分辨率与动态分辨率。HunyuanOCR-1.5 轻量端到端 VLM，集成 DFlash 投机解码加速，支持 PC 端 llama.cpp 部署。

🎯

YOLO 目标检测

支持 Board / Grid / Product 多种检测模式，精准定位商品区域。与 OCR 和 Embedding 模块联动，实现检测-识别-检索的完整链路。
